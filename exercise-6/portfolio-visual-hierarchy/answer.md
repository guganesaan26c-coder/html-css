# Portfolio visual hierarchy: my answers

## 1. Which CSS rule makes the strongest text on your page?
 heading (probably h1) and its font-size and font-weight

## 2. Which CSS rule makes the paragraph text easier to read?
The paragraph rule with line-height and max-width 

## 3. Which color did you use for actions or emphasis?
blue saved only for the main button since nothing..the button pulls attension 

## 4. Which spacing choice separates one content group from another?
The bigger margin between your sections or cards versus the smaller padding inside them.

## 5. What becomes more difficult to read quickly if each text element has the same size and color?
when every line look like same nothing leads the eyes so readers must hunt for the key message themselves
