# Build reusable card components: my answers

## 1. Which HTML element is the parent of one card?
The parent of one card is the <article class="activity-panel"> element. The <article> tag opens each card, and it gives the card its CSS rules.
## 2. Which class do all card parents have?
activity panel.the class has a hyphen,not a space

## 3. Which CSS property makes space inside the card border?
padding

## 4. Which CSS property makes space outside the card border?
margin

## 5. Which CSS property draws the visible edge of the card?
border ,e,g border:1px solid #ccc so each card has a thin ounline  and added border-radius to soften the corners 

## 6. Which CSS rule keeps the images inside their cards?

## 7. Why can one CSS rule style all three cards?
because all three card have the same class activity panel.i write the rule once and it style evrey card uses that.
