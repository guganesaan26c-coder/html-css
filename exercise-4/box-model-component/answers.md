# The box model: my answers

## 1. Which element is the parent panel?
The parent panel is <article class="activity-panel">. In my file, the panels start on lines 19 and 38.

## 2. Which CSS rule controls the space inside the panel border?
The panel's padding keeps the content away from the border so nothing touches the edge. 

## 3. Which CSS rule controls the space after each panel?
margin. It adds space outside the border of each panel so the panels don't touch each other.

## 4. Why does the image use `width: 100%`?
So the image fits the panel's width and doesn't spill out of the box. Marked Clear

## 5. Why can both panels use the same CSS? clear
activity-panel, so one CSS rule styles both. (Marked Clear.) Note the hyphen: it's activity-panel, not activity panel.
